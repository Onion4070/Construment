# Construment Viewer

以下は本アプリで使えるキーボードによる音階操作と、viewer → RP2350 間のシリアルプロトコルの仕様です。

## 音階操作
- A, B, C, D, E, F, G : 対応する音を送信します。
- s : Silence（無音）を送信します。

修飾キー（押しながらノートキーを押す）:
- h : 1オクターブ下（-12 半音）
- j : 半音下（-1 半音）
- k : 半音上（+1 半音）
- l : 1オクターブ上（+12 半音）

左右選択（押しながらノートキー / s を押す）:
- n を押しながら → 左側（left）のみを更新します。
- m を押しながら → 右側（right）のみを更新します。
- どちらも押さない場合 → 両側を更新します。

例:
- `n` を押しながら `A` を押す → 左だけ A4 に設定
- `m` を押しながら `s` を押す → 右だけ Silence に設定

注: パネルにフォーカスが必要です。DrawPanel をクリックしてからキーを押してください。

## シリアルプロトコル（viewer → RP2350）
viewer は以下のバイナリ・フレームを送信します：

```
[0xAA][size=3][cmd=0x01][note_l][note_r][0xBB]
```

- `0xAA` : フレーム開始バイト
- `size` : payload 長（この実装では 3）
- `cmd` : コマンド ID（`0x01` = SET_DEFAULT_NOTE）
- `note_l` : 左側ノート（`Scale::Note` enum の値をそのまま uint8）
- `note_r` : 右側ノート（同上）
- `0xBB` : フレーム終了バイト

RP 側は上記を受け取り `cmd == 0x01` のとき `setDefaultNote((Scale::Note)note_l, (Scale::Note)note_r)` を呼び、既定ノートを更新します。
